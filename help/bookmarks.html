Bookmarks

Bookmarks are executable scripts stored in a bookmarks directory next to your Chimera configuration file. Each script appears in the Bookmarks menu using its file name.

Location

If your configuration file is ~/.local/state/chimera.json, bookmarks are loaded from:

~/.local/state/bookmarks/

Example

Create an executable file such as my-server:

#!/usr/bin/env sh
exec ssh my-server

Then make it executable:

chmod +x ~/.local/state/bookmarks/my-server

Menu Behavior

  • Hidden files and directories are ignored.
  • Bookmarks are sorted by file name.
  • The menu title is the file name without its final extension.
  • Use Bookmarks > Refresh after adding, removing, or renaming scripts.

Bookmarks run as terminal sessions, so scripts can launch SSH, local commands, or small project workflows.
