Bookmarks

Bookmarks are menu entries defined in bookmarks.json next to your Chimera configuration file. Entries can launch commands, create separators, and group related commands into submenus.

Location

If your configuration file is ~/.local/state/chimera/configuration.json, bookmarks are loaded from:

~/.local/state/chimera/bookmarks.json

Example

Create bookmarks.json with entries like this:

[
  {
    "title": "My Server",
    "command": "ssh",
    "args": ["my-server"]
  },
  {
    "type": "separator"
  },
  {
    "title": "Projects",
    "items": [
      {
        "title": "Chimera",
        "command": "/bin/zsh",
        "args": ["-lc", "exec $SHELL"],
        "cwd": "projects/chimera"
      }
    ]
  }
]

Editor

Use Bookmarks > Edit Bookmarks to open the bundled HTTY editor, or run it directly:

bin/chimera-bookmarks-editor

Menu Behavior

  • Entries appear in the same order as the JSON array.
  • Use {"type": "separator"} to insert a menu separator.
  • Use items to create a submenu.
  • args defaults to an empty array.
  • Relative cwd values are resolved next to the Chimera configuration file.
  • The bundled editor refreshes the Bookmarks menu after saving.

Bookmarks run as terminal sessions, so they can launch SSH, local commands, or small project workflows.
